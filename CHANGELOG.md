# Changelog

All translator bot changes and updates are here.


## 2.0 [2026-07-27]

### Fixed
- Preserved emojis during translation using stable placeholders (`__EMOJI_n__`) so placeholders no longer leak into translated output.
- Normalized Discord emoji markdown image syntax (for example `![🫣](https://discord.com/assets/....svg)`) into plain emoji before translation.
- Kept backward compatibility for older leaked placeholder format (`[EMOJI0]`).

### Update
- Added more languages:
Arabic, Hindi, Turkish, Indonesian, Thai, Czech, Romanian
